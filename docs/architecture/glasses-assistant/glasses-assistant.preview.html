One turn

  • Wake phrase heard on the phone, then one photo from the glasses and one spoken question
  • The phone sends image + transcript to the gateway on the Mac; the answer returns on the same request and is spoken
  • Nothing in the default path leaves the tailnet; the public web is reached only by the browser agent

Gates that stay with the operator

  • Signing, App Store Connect, TestFlight and device registration
  • Exposing the gateway on Tailscale Serve and any LiteLLM config change
  • Purchases, sends to other people, deletions: spoken confirmation, never automatic

Planned, not live

  • Everything tagged planned is on paper as of 2026-11-20
  • LiteLLM, rapid-mlx, the DGX pair, the daily worker and the vault are live per the operator's log
  • Vision through LiteLLM itself is unverified: the log proves vision on the backends, not through :4000
